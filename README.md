# Sistema de Livraria

## 1. Introdução e Objetivo

Este documento detalha a arquitetura de dados desenvolvida para o sistema de gestção de livrarias. O objetivo do sistema é automatizar os processos comerciais e de cadastro da empresa, implementando operações de CRUD (Create, Read, Update, Delete) em entidades básicas, uma rotina principal de vendas com relacionamentos e chaves estrangeiras, além de consultas avançadas utilizando JOIN e geração de relatórios gerenciais, utilizando Java (Swing/JDBC) e MySQL sob o padrão arquitetural MVC.
